# DeepAgents-8-子代理-子智能体

## 一、先建立整体层级关系

```bash
create_deep_agent(...)
        │
        ▼
┌──────────────────────────────────────┐
│         Deep Agent Harness           │
│                                      │
│  Middleware / Tools / Skills / ...   │
│                                      │
│  ┌────────────────────────────────┐  │
│  │         Main Agent             │  │
│  │                                │  │
│  │  1. 理解用户需求                 │  │
│  │  2. 制定计划                    │  │
│  │  3. 决定是否委派                 │  │
│  │  4. 汇总子智能体的结果            │  │
│  └───────────────┬────────────────┘  │
│                  │                   │
│             task(...)                │
│                  │                   │
│      ┌───────────┼───────────┐       │
│      ▼           ▼           ▼       │
│  Researcher   Coder       Reviewer   │
│   研究智能体   编码智能体    审查智能体   │
│      │           │           │       │
│      ▼           ▼           ▼       │
│    研究结果    代码结果     审查结果     │
│      └───────────┼───────────┘       │
│                  ▼                   │
│          Main Agent 汇总              │
└──────────────────┬───────────────────┘
                   ▼
             最终回答用户
```

| 层次       | 主要职责        | 你需要理解的重点                        |
| ---------- | --------------- | --------------------------------------- |
| Harness    | 组装 Agent 能力 | 配置 subagents、模型、工具和 Middleware |
| Main Agent | 任务协调者      | 决定任务如何拆分、委派给谁、怎样汇总    |
| Subagent   | 任务执行者      | 根据自己的上下文、工具和指令完成工作    |
